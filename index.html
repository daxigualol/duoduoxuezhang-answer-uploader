离线编辑页

批量答案录入 · 多多学长

点右下角 “批量答案” 打开录入面板：可以网格点选，也可以在“批量粘贴”里一次贴入 100 题的答案。

题型

81–100 为多选（可勾选多个字母），1–80 为单选。 面板已按此默认设置，单格也可以手动改；粘贴时若某题写了多个字母，会自动标成多选。

这里只能编辑，不能上传。

浏览器不允许网页带着别站的登录 Cookie 跨域提交，所以本页的上传必定失败。 正确做法：先在这里把答案录好 → 面板里“批量粘贴 → 导出当前答案 / 复制” → 到 www.duoduoxuezhang.com 页面里用油猴脚本打开同样的面板 → 粘贴 → 批量上传。

三步走

  1. 本页录入答案（网格点选，或 1.A 2.B 3.ABC 这样的文本粘贴）。
  2. 打开“批量粘贴”标签，点 导出当前答案，再点 复制。
  3. 在网站上打开面板 → “批量粘贴” → 粘贴 → 解析并填入 → 回“网格录入”核对 → 底部 批量上传。

答案文本格式

  • 每行一题：1.A、2.B、3.ABC
  • 也可以连写：1.A 2.B 3.ABC、1、A 2 B 3:ABC
  • 没有题号时，按“起始题号”往后依次填入：A B AB C
  • 多个字母表示多选，顺序无所谓，BA 与 AB 等价。

题号规则

提交的 questionId 由 科目-年份-三位题号 拼成，例如第 3 题：computer-2026-003， 第 100 题：computer-2026-100。科目默认 computer，年份默认 2026，可在面板顶部修改。

本页只做本地存储，答案保存在浏览器 localStorage，刷新不会丢。面板底部右侧的 清空 按钮可一键删除全部答案（带二次确认）。
