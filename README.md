# 批量答案录入 · 多多学长

人工点选 120 道题的答案（第 81–100 题为多选），再逐题调用 `POST /api/answer` 批量提交的小工具。

## 文件

| 文件 | 作用 |
| --- | --- |
| `answer-uploader.user.js` | 主程序。油猴脚本，也是可粘贴到控制台的单文件脚本 |
| `index.html` | 离线编辑页：先在这录答案，导出文本，再到网站上导入 |
| `dev/parser.test.mjs` | 粘贴解析逻辑的单元测试（`node dev/parser.test.mjs`） |

## 为什么必须在网站页面里上传

请求带 `credentials: "include"`，依赖 `duoduoxuezhang.com` 的登录 Cookie。
从别的页面（本地文件、其他域名）发起属于跨域请求，浏览器会先做 CORS 预检；
站点没有放行你的来源，请求会直接被拦掉，表现为 `Failed to fetch`。
所以面板要跑在 `www.duoduoxuezhang.com` 自己的页面里——同源请求，Cookie 自动带上，没有 CORS 问题。

## 安装

### 方式一：油猴脚本（推荐）

1. 浏览器安装 Tampermonkey（篡改猴）。
2. 扩展面板 → 添加新脚本 → 清空模板 → 粘贴 `answer-uploader.user.js` 全文 → `Ctrl+S` 保存。
3. 打开并登录 `https://www.duoduoxuezhang.com/`，右下角出现蓝色 **批量答案** 按钮。

### 方式二：控制台（临时用）

1. 登录网站，`F12` → Console。
2. 粘贴 `answer-uploader.user.js` 全文，回车。
3. 同样出现右下角按钮。刷新页面后消失，需重新粘贴。

### 方式三：DevTools Snippets（免装扩展，可复用）

1. 登录网站，`F12` → Sources → Snippets → 新建。
2. 粘贴全文保存，之后每次在网站上右键该 snippet → Run 即可。

## 录入

面板顶部是 **科目** / **年份**，默认 `computer` / `2026`。`questionId` 规则：
`科目-年份-三位题号`，例如第 3 题 `computer-2026-003`、第 120 题 `computer-2026-120`。

### 网格录入

- 单击 `A` `B` `C` `D` 选择，再点同一个字母取消。
- 题型默认已按 **81–100 多选、1–80 与 101–120 单选** 设好，格子右上角的 **多** 自动点亮。
- 单元格右上角 **多** 点亮 = 多选题，此时字母可多选；不点亮 = 单选，点新字母会替换旧答案。单格可以手动改。
- 快捷键：`1`~`4` 录入（1=A、2=B、3=C、4=D，小键盘也可以）、`M` 切换多选、`Backspace` 清空本格、方向键移动、`Enter` 下一题。
- 勾选“录入后跳下一题”可连续敲，120 题大约 240 次按键（多选格不自动跳，避免漏选）。
- 想改某一段的题型：用“多选范围 → 设为多选/设为单选”；误改了按“恢复默认题型”。

### 批量粘贴

每行一题或空格连写都行：

```
1.A
2.B
3.ABC
4.D
```

或 `1.A 2.B 3.ABC 4.D`，也认 `1、A`、`2 B`、`3:ABC`、全角字符。
整段没有题号时（`A B AB C`），从“起始题号”开始按顺序填。
某题写了多个字母（如 `83.ABC`）会自动标成多选；解析后自动回到网格视图，可以逐题核对。

答案会实时存进浏览器 localStorage，刷新不丢。

## 上传

底部“批量上传”会：

1. 按题号从小到大，只提交已作答的题（会提示还有几题空着）。
2. 每题 `POST /api/answer`，body 为 `{"questionId":"computer-2026-003","selected":"C"}`，多选就是 `"selected":"ABC"`。
3. 串行执行，每题之间默认间隔 `300ms`，可在面板底部改（0–5000）。
4. 进度条 + 日志：每题显示 `题号 答案 → HTTP 状态`，失败的格子标红。
5. 结束给汇总；失败项可点 **重试失败** 只重跑那几题。
6. **停止** 立即中断（含正在飞的那一条）。

**试传 1 题** 先发一条看返回，确认格式/登录正常，再跑全量。

判断成功的规则：HTTP 2xx，且响应体不是 `success:false` / `ok:false` / `code` 不为 0、200、ok、success。
如果站点返回别的字段含义，日志里保留了原始响应文本，看一眼就知道要不要改。

请求头按你给的样例复制了 `accept`、`accept-language`、`content-type`；`priority: u=1, i` 是浏览器自己的调度提示，
JS 里设了也无效，故省略；`referer` 由浏览器按当前页面自动带上。

## 常见问题

**提示“连续 3 次网络错误” / `Failed to fetch`**
不在目标站点页面里运行（或登录已掉）。刷新 `www.duoduoxuezhang.com`，确认已登录，用油猴方式重试。

**提示“返回了 HTML 页面”**
登录态失效，接口把请求重定向到登录页了。重新登录即可。

**能改题号规则吗**
面板顶部改科目/年份即可；题号固定补零到 3 位（`003`）。

**答案会不会提交错题**
只按 `questionId` 拼 `科目-年份-题号`，与页面上第几题无关。批量前先用“试传 1 题”核对一条。

**间隔设多少合适**
保守起见 300ms 起步。若出现 429/5xx，调大到 800–1000ms。
